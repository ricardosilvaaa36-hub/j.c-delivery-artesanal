# J.C Delivery Artesanal

Acesse o drive as pegue as informações do drive também, tem valores informações dos produtos 

https://drive.google.com/drive/folders/1yIjX3vHT2o91uwCVyfEfFlUb8d-Ekxmt

Crie um site completo, moderno e profissional para a J.C Hamburgueria, uma hamburgueria localizada em Aparecida do Taboado, Mato Grosso do Sul.



Quero um site de delivery com aparência de aplicativo profissional, fácil de usar pelo celular, inspirado na experiência de plataformas de delivery, mas com identidade visual própria.



Não crie apenas uma landing page estática. Desenvolva uma experiência interativa com cardápio, produtos, carrinho de compras e checkout que encaminha os pedidos pelo WhatsApp.



1. IDENTIDADE DA MARCA



Nome: J.C Hamburgueria



Slogan: "Feito com carinho, servido com alegria!"



WhatsApp: (67) 99242-0331



Link para pedidos: https://wa.me/5567992420331



Instagram: https://www.instagram.com/jc_burges_/



Endereço: Avenida da Saudade, 2060, Jardim Aeroporto, Aparecida do Taboado - MS.



Utilize a logo enviada como referência visual principal. Preserve a personalidade da mascote, as cores e a identidade da marca.



Se a logo estiver disponível entre os arquivos enviados, utilize-a diretamente.



2. DESIGN E IDENTIDADE VISUAL



Crie um design atraente, com aparência de hamburgueria moderna e artesanal.



Paleta de cores:



- Verde principal: #00C66A

- Verde escuro: #064D25

- Amarelo dourado: #FFD166

- Vermelho: #E83D24

- Branco: #FFFFFF

- Fundo claro: #F7F7F7



Utilize:



- Fotos apetitosas de hambúrgueres.

- Cards com cantos arredondados.

- Botões grandes e intuitivos.

- Tipografia moderna.

- Sombras suaves.

- Ícones minimalistas.

- Animações discretas.

- Excelente contraste entre textos e fundos.



O site deve transmitir confiança, qualidade, fome e vontade de pedir.



Evite aparência genérica, excesso de elementos e cores desorganizadas.



3. PÁGINA INICIAL



Crie uma página inicial com:



- Cabeçalho com logo e nome da hamburgueria.

- Botão do carrinho com contador de itens.

- Banner principal com imagem de hambúrguer artesanal.

- Título: "O sabor que conquista a cada mordida!"

- Subtítulo: "Feito com carinho, servido com alegria!"

- Botão destacado: "Ver cardápio".

- Seção "Mais pedidos".

- Seção de combos.

- Categorias de produtos.

- Chamada para pedir pelo WhatsApp.

- Rodapé com endereço, telefone e Instagram.



Inclua um botão flutuante do WhatsApp que abra uma conversa com a hamburgueria.



4. CARDÁPIO DIGITAL



Crie categorias com ícones:



- Hambúrgueres.

- Combos.

- Hot-dogs.

- Porções.

- Bebidas.

- Adicionais.



Cada produto deve possuir:



- Foto de boa qualidade.

- Nome.

- Descrição curta.

- Preço em reais.

- Botão "Adicionar".

- Opção de selecionar quantidade.

- Adicionais, quando aplicável.



Crie uma navegação por categorias com rolagem horizontal no celular.



Adicione uma barra de pesquisa para localizar produtos pelo nome.



Os cards devem ser bonitos, com imagens bem enquadradas, preço em destaque e botão de adicionar fácil de encontrar.



Utilize produtos de demonstração apenas para montar o layout. Organize-os para que eu possa substituir facilmente pelos produtos e preços reais. Não apresente informações fictícias como se fossem oficiais.



5. CARRINHO DE COMPRAS



Implemente um carrinho realmente funcional.



O cliente deve poder:



- Adicionar produtos.

- Remover produtos.

- Aumentar e diminuir quantidades.

- Escolher adicionais.

- Informar observações sobre cada produto.

- Visualizar subtotal.

- Visualizar taxa de entrega.

- Visualizar total do pedido.

- Continuar comprando.

- Avançar para o checkout.



Salve o carrinho no LocalStorage para que os produtos permaneçam após atualizar a página.



Exiba o carrinho em uma gaveta lateral ou página própria, com boa experiência em dispositivos móveis.



6. CHECKOUT E FINALIZAÇÃO PELO WHATSAPP



Crie uma tela de checkout simples e organizada.



Campos:



- Nome do cliente.

- Telefone para contato.

- Tipo de pedido: entrega ou retirada.

- Endereço de entrega.

- Número da residência.

- Bairro.

- Complemento e referência.

- Forma de pagamento.

- Troco para dinheiro, quando necessário.

- Observações gerais.



Formas de pagamento configuráveis:



- Pix.

- Dinheiro.

- Cartão.



Valide os campos obrigatórios de acordo com o tipo de pedido.



Antes de finalizar, mostre um resumo completo com os produtos, quantidades, adicionais, subtotal, taxa de entrega e total.



Ao clicar em "Finalizar pedido pelo WhatsApp", gere uma mensagem organizada contendo todos os dados do pedido.



Envie o cliente para:



https://wa.me/5567992420331?text=MENSAGEM_CODIFICADA



A mensagem deve ser codificada corretamente para URL e conter o nome dos produtos, quantidades, adicionais, valores e dados de entrega.



Não simule pagamento aprovado nem confirmação automática. O cliente precisa enviar a mensagem no WhatsApp para concluir o envio do pedido.



7. MENU LATERAL



Crie um menu lateral inspirado na referência visual fornecida.



Ele deve apresentar:



- Logo da hamburgueria.

- Nome J.C Hamburgueria.

- Horários de funcionamento.

- Telefone.

- WhatsApp clicável.

- Endereço.

- Botão "Como chegar".

- Link para Instagram.



O botão "Como chegar" deve abrir o Google Maps com o endereço informado.



O menu precisa abrir e fechar suavemente, ter um botão de fechar visível e funcionar bem no celular.



Não invente horários de funcionamento. Enquanto não forem fornecidos, mostre "Consulte nossos horários pelo WhatsApp".



8. EXPERIÊNCIA MOBILE



Priorize o uso em celulares Android e iPhone.



Implemente:



- Layout totalmente responsivo.

- Navegação simples com uma mão.

- Botões grandes.

- Categorias com rolagem horizontal.

- Carrinho acessível.

- Menu lateral funcional.

- Botão flutuante do WhatsApp.

- Barra inferior com atalhos para início, cardápio e carrinho, quando apropriado.

- Feedback visual ao adicionar produtos.

- Imagens otimizadas.

- Estados vazios amigáveis.



Não permita que menus, botões fixos ou barras inferiores cubram o conteúdo principal.



9. CONFIGURAÇÕES DOS PRODUTOS E DO NEGÓCIO



Organize os dados dos produtos e as configurações comerciais de forma centralizada.



Deixe simples editar:



- Nome do produto.

- Descrição.

- Imagem.

- Preço.

- Categoria.

- Disponibilidade.

- Adicionais.

- Taxa de entrega.

- Horários.

- Telefone.

- Endereço.

- Formas de pagamento.



Não invente preços oficiais, horários ou taxas.



10. FUNCIONALIDADES ADICIONAIS



Implemente:



- Formatação de moeda brasileira.

- Pesquisa e filtros.

- Validação dos formulários.

- Persistência do carrinho.

- Estados de carregamento.

- Mensagens de erro compreensíveis.

- Acessibilidade básica.

- SEO com título e descrição.

- Links de contato funcionais.



Utilize componentes reutilizáveis e mantenha o código organizado.



11. TECNOLOGIA E QUALIDADE



Utilize a stack padrão recomendada pelo Lovable, preferencialmente React, TypeScript e Tailwind CSS.



Se o projeto já tiver uma estrutura existente, preserve o que estiver funcionando.



Não adicione Supabase ou integrações pagas sem necessidade. O primeiro objetivo é ter um site de pedidos pelo WhatsApp que funcione corretamente.



Não deixe botões decorativos sem ação. Não utilize links fictícios para funcionalidades principais.



Verifique o fluxo completo de compra, os cálculos do carrinho e a geração da mensagem do WhatsApp.



12. RESULTADO ESPERADO



Entregue um site visualmente impressionante, funcional, responsivo e pronto para personalização.



A primeira impressão deve ser a de um delivery profissional.



Prioridades:



1. Design bonito e identidade visual da J.C Hamburgueria.

2. Excelente experiência no celular.

3. Cardápio fácil de navegar.

4. Carrinho funcional.

5. Checkout simples.

6. Pedidos enviados pelo WhatsApp.

7. Código organizado e fácil de manter.



Comece implementando o site completo. Não se limite a descrever o que faria. Ao concluir, revise o layout, teste os fluxos principais e corrija os problemas identificados.
